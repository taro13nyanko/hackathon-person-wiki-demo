# 人物Wiki — ハッカソン提出用デモ

このフォルダは、人物Wikiの表示機能、時系列データ、早送り体験を収録したハッカソン提出版です。

## 公開版

GitHub Pagesでは `index.html` が公開入口です。人物ページの閲覧、検索、期間・グループ・備考を使った3枚の早送りを利用できます。

左側の「新規作成」と各人物ページの「編集」から、Wikipediaのように画面上で人物情報を追加・更新できます。編集内容は閲覧者のブラウザ内に保存され、公開版の共通データや他の閲覧者の画面は変更しません。共通データへ正式に反映する場合は、元の人物WikiフォルダをAIまたはコード編集で更新して再ビルドします。

AI APIはRender上のバックエンドから呼び出します。`GEMINI_API_KEY` があれば無料枠のあるGeminiを優先し、未設定の場合だけOpenAIを使います。APIキーはブラウザやGitHub Pagesへ渡さず、RenderのSecretとして管理します。

## 公開AIバックエンド

1. [Render Blueprint](https://render.com/deploy?repo=https://github.com/taro13nyanko/hackathon-person-wiki-demo)を開く
2. GitHubでログインし、表示されたサービスを作成する
3. `GEMINI_API_KEY` にGoogle AI StudioのAPIキーをSecretとして入力する
4. デプロイ完了後、`https://people-wiki-fast-forward-api.onrender.com/api/health` が開くことを確認する

公開サービスはGitHubへの更新を自動反映します。1つの接続元につき1分5回までに制限しています。Render側でサービス名を変更した場合は、`build_people_wiki.py` 内の公開API URLも同じURLへ変更してください。

## ビルド

```powershell
python exbrain\scripts\build_people_wiki.py
```

生成物は `人物wiki/people_wiki_ver1.0.html` です。サーバー不要で、そのHTMLをブラウザで開くだけで閲覧できます。

## AI早送りを使う

AI生成を使う場合は、単一HTMLを直接開くのではなく、同梱の小さなバックエンドから起動します。

1. `start_wiki.bat` をダブルクリックする
2. 初回だけ、表示された入力欄へOpenAI APIキーを貼り付けてEnterを押す
3. 人物Wikiがブラウザで自動的に開く

二回目以降はキー入力不要です。終了するときは、起動時に開いた黒い画面を閉じます。

APIキーはHTMLや人物データへ埋め込まれません。`.env` はGitの対象外です。

人物またはカテゴリの「≫ 早送り」から、以下を指定できます。

- 開始日・終了日
- グループ
- 3枚固定の早送り
- 必要な場合だけ入力する備考欄

生成した早送りは、スライドをクリックすると次へ進み、3枚目の次は1枚目へ戻ります。APIが未設定または一時的に失敗した場合は、Wiki内のローカル構成へ自動的に切り替わります。

## デモの見どころ

- 主人公「神谷ハル」は2026年時点で30歳。高校入学時の2012年から人物Wikiを使い始めた想定です。
- 高校コミュニティ30人分の人物ページと、2012〜2026年の文化祭・部活・進路・交際・再会などの履歴を収録しています。
- 人物ページの「≫ この人との関係を早送り」から、その人物との時間を文章スライドで再生できます。
- 左側で「高校コミュニティ」を選び「≫ 高校コミュニティを早送り」を押すと、30人の出来事を年ごとに圧縮して再生します。
